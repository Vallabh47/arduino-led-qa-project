# Arduino LED Blinking - QA Documentation Project

## 1. Project Overview

This project demonstrates a basic embedded system using an Arduino to
control an LED. The project is developed and documented using GitHub
collaborative tools for quality assurance, issue tracking, problem solving,
and project monitoring.

## 2. Objective

The objective of this project is to implement a simple LED blinking system
and demonstrate how GitHub can be used to:

- Maintain embedded-system source code
- Document project information
- Identify and track QA issues
- Perform root-cause analysis
- Collaboratively solve problems
- Track changes using commits and branches
- Maintain a history of issue resolution

## 3. Hardware Requirements

- Arduino board
- LED
- 220Ω resistor
- Connecting wires
- Breadboard
- USB cable

## 4. Software Requirements

- Arduino IDE
- GitHub

## 5. Working Principle

The Arduino configures the LED pin as an output. The LED is switched ON
for one second and then switched OFF for one second repeatedly.

The basic sequence is:

1. Configure LED pin as OUTPUT
2. Turn LED ON
3. Wait for 1 second
4. Turn LED OFF
5. Wait for 1 second
6. Repeat the process

## 6. Source Code

The main source code is available in:

`led_blink.ino`

## 7. Quality Assurance Approach

The project uses GitHub Issues to identify and document potential problems
in the embedded system.

Each QA issue will contain:

- Problem description
- Severity
- Expected behaviour
- Actual behaviour
- Possible root cause
- Proposed solution
- Resolution status

## 8. GitHub Collaboration

GitHub features used in this project include:

- Repository
- README documentation
- Issues
- Issue comments
- Labels
- Branches
- Commits

Issues are linked with development changes so that problems can be traced
from identification to resolution.

The final system should provide reliable LED blinking while maintaining
proper documentation of identified problems, corrective actions, and
development history through GitHub.
